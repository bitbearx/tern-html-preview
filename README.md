# HTML Preview for Tern

手动预览 HTML，不安装文件路由，不接管原有文件打开行为。0.2.0 保留本地文件直接预览，并为远程入口增加基于 `cx.docs:read()` 返回值的单文件源码快照。**此 SDK 的远程来源限制见下文，不能将快照流程视为已验证的通用远程文件传输。**

## 安装

需要桌面版 Tern 和 `python3`。已在 macOS 的 Tern 0.9.23（35c63ab）验证；其他平台尚未实测。

```sh
cd tern-html-preview
tern plugin link .
```

插件 ID 为 `html-preview`。修改插件文件后 Tern 会自动重新加载；卸载链接：

```sh
tern plugin unlink html-preview
```

## 按钮在哪里、何时出现

- 按钮位于 **Files 文件树顶部工具栏**，提示文字为“预览 HTML”，使用地球图标。
- 跟随 Tern 原生工具栏规则：鼠标移入 Files 面板时显示，按钮获得键盘焦点时也显示。
- SDK 不提供依据选中文件动态显隐的接口，因此按钮不会只在选择 HTML 时出现；在 Changes、Refs 页签中也可能显示。
- 在 Files 页签选择一个 `.html` / `.htm` 文件后点击。扩展名不区分大小写；本地文件直接打开，远程入口生成源码快照。
- 未选择、选择多个文件或非 HTML 时提示原因；文件读取失败时提示错误，不用空内容替代。无显式选择时，Tern 可能把文件树当前光标行作为选择传给插件。

## 源码与预览

当前焦点是本地或远程 HTML 源码面板时，命令面板提供 **HTML Preview: 预览当前 HTML**；普通文本和浏览器面板不显示此命令。Files 收起时也可以使用。

插件不会把普通文件点击改成自动渲染，也不会改变 `tern open --wait`。Tern 自身的行为仍然保留：此版本单击文件可以显示临时源码预览，正式打开 HTML 可能直接进入内置浏览器。需要持久源码面板时，可以带行号打开：

```sh
tern open '/绝对路径/页面.html:1'
```

### 本地文件

同一窗口已有相同文件的浏览器面板时，预览按钮会聚焦该面板，不重复创建、不重新加载。中文、空格、`#`、`%`、`?`、`+` 等文件名字符会正确编码；符号链接解析到真实文件后复用相同预览。链接页面的相对资源以真实文件所在目录为基址。

- 展示的是**磁盘上已保存的内容**，不是编辑器中的未保存缓冲区。
- 修改后先保存，再使用内置浏览器的刷新按钮；没有自动刷新。
- 关闭预览不会关闭源码面板或终端。刷新、导航、关闭均使用 Tern 原生控件。
- 页面导航到其他文件后，再次预览原文件不会覆盖它，而是查找或新建原文件的预览。

### 远程入口：单文件源码快照

按当前选择，直接调用 `cx.docs:read(path)`，将返回的完整字符串保存为本机私有 HTML 快照。不会通过面板摘要拼接源码，不使用 SSH，不在远端安装插件或启动服务。

- 内联 CSS、JavaScript、SVG 和 `data:` 资源随 HTML 保留；不下载、解析或重写外部资源。相对路径资源缺失就加载失败。
- 快照以窗口、主机地址和文件路径隔离，同名文件不互相覆盖。它保存的是文档接口返回的内容，可能包含该接口所读取缓冲区中的未保存修改。
- 再次点击插件预览入口：重新读取源码，原子更新快照并刷新同一面板。浏览器自己的刷新按钮只重载已有快照，不重新取源码。
- 当前 Tern 浏览器自动化接口无法接受远程面板作为创建目标，因此会切到**本机标签页右侧**显示快照。优先复用已有本机标签；没有本机面板时创建一个本机终端标签承载预览。
- 关闭预览后异步清理不再被浏览器或在途请求引用的快照。插件重载后根据活动 URL 回收，不依赖旧 VM 的面板缓存；异常退出仍可能留下快照文件。
- 快照位于插件数据目录的 `snapshots/` 下，窗口与来源使用哈希目录，目录权限为 `0700`、文件为 `0600`。UTF-8 BOM 保证文档接口返回的 Unicode 源码不会被旧的 HTML charset 声明误解码。

#### 已知 SDK 来源限制

在 Tern 0.9.23 的隔离探针中，焦点是远程 HTML 源码面板时，`cx.docs:read(path)` 仍读到了**本机同路径文件的缓冲区**，包括本机未保存的修改。该接口没有显式的主机参数。

因此，本版本按用户指定直接使用此接口，但**不能保证取到真正的远程内容**：远端独有而本机不存在的路径可能读取失败，同名路径可能读到本机内容。快照的主机隔离只隔离缓存，不修复读取来源；没有静默回退到 SSH 或其他通道。请核对预览内容，不将此模式用于必须保证远端来源的场景。

## 范围与安全

- 本地普通 HTML 继续直接加载。远程入口只生成一个 HTML 快照，不复制资源目录。
- 使用 `file://` 加载，不启动 HTTP 服务。普通相对 CSS、JavaScript 和交互已经实测；ES Modules、`fetch()`、跨域请求及需要 dev server 的项目应使用合适的 HTTP 环境，不绕过浏览器安全策略。
- 预览会执行 HTML 中的脚本，也可能产生页面自身的网络请求。只预览可信内容。
- 新建的浏览器面板使用 `html-preview` profile；复用已有同址面板时保留该面板原来的 profile。独立 profile 不等于断网或权限沙箱。
- 插件通过参数数组运行 `python3 resolve_file.py`（本地路径检查）和 `python3 snapshot_file.py`（本机快照写入与回收），不拼接 shell 命令、不主动上传文件。HTML 经标准输入传入快照写入器，不进入命令行参数；运行环境缺少 `python3` 时会提示错误。

## 验证

核心文件测试：

```sh
python3 -m unittest -v test_resolve_file test_snapshot_file
```

真实界面测试（会打开独立 Tern 窗口）：

```sh
HTML_PREVIEW_UI_TEST=1 python3 -m unittest -v test_preview
```

界面测试隔离 HOME、Tern 配置、守护进程 socket 和可写 PATH，结束后清理自己的窗口和会话。本地场景覆盖无效选择、手动触发、CSS/JS、交互与符号链接复用。源码快照场景通过两个真实 loopback 守护进程入口验证约 2 MB 的长行内联脚本、2,501 行附加源码、外部资源不复制、更新刷新、主机隔离、关闭清理及插件重载后的清理。**Loopback 与本机共享文件系统，这些测试不证明真实远程读取的来源正确。**
